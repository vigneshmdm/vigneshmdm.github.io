# Vignesh Karuppasamy D M — Portfolio

Static single-page portfolio, ready for GitHub Pages.

## Publish

1. Create a repo (e.g. `vigneshmdm.github.io` or `portfolio`).
2. Copy the contents of this folder to the repo root (`index.html` and `assets/`).
3. In repo Settings → Pages, deploy from the `main` branch, root folder.

## Files

- `index.html` — page markup
- `assets/style.css` — styles
- `assets/script.js` — mobile nav + scroll reveal
- `assets/photo.jpg` — profile photo (placeholder silhouette; replace with real photo)
- `assets/resume.pdf` — downloadable resume
- `assets/logos/` — AMD, Visteon, University of Waterloo, Cadence, IEEE (SVG, sourced from Wikimedia Commons)
